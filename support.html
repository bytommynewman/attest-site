Common questions

The Approve button is not shown.
Only people listed as approvers in Space settings → Document control see Approve and Send back to draft, and whoever submitted or last edited a version can't approve it unless the space allows that. Anyone can submit a draft for review.
Approve is greyed out.
Tick the statement above it first. It names the version you're signing, and the wording is saved with your signature.
"That did not go through."
The page changed after it was submitted, so the signature was refused. Reload the page, review the new version and submit it again.
"Approved, but the page is not locked."
The app could not add edit restrictions to that page. The HTTP status is in the panel and the audit trail; please send it to support. The approval itself stands, but the page is still editable.
Signatures disappeared after an edit.
By design. A signature belongs to the page version it was given against; publishing a new version resets the document to Draft and records that in the audit trail.
Where is the audit trail?
Per page: Document control → Show audit trail. Per space, as CSV: Space settings → Document control → Audit export.

Verifying an audit export

Each row of an export carries a sequence number, the previous entry's hash and its own hash. You can check them without the app:

  1. In Space settings → Document control → Audit export, export the trail and copy each batch into its own .csv file.
  2. Download verify-audit.mjs. It needs only Node.js.
  3. Run node verify-audit.mjs batch-1.csv batch-2.csv, giving it every batch so each page's chain is complete.

It prints OK or FAIL for each page, and exits with an error if an entry was altered or is missing. Each entry's hash is the SHA-256 of this JSON array: [seq, prev_hash, page_id, space, timestamp_utc, actor_id, actor_name, from_state, to_state, version, note]. Entries from before chaining was added are counted, but can't be checked. For an export limited with a Since date, add --partial: its chains start part-way through, so it can't confirm the earlier entries are there.

A chain can't reveal that its newest entries were removed. Keep the newest hash from each export somewhere outside Confluence, and check that it still appears in later exports.

Data

Attest runs entirely on Atlassian infrastructure. See the privacy policy. Before uninstalling, export your audit trail: Atlassian keeps an uninstalled app's data for 28 days, and it can only be recovered if you ask within 21.
