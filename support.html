Common questions

The Approve button is not shown.
Only people listed as approvers in Space settings → Document control see Approve and Send back to draft. Anyone can submit a draft for review.
"Approved, but the page is not locked."
The app could not add edit restrictions to that page. The HTTP status is in the panel and the audit trail; please send it to support. The approval itself stands, but the page is still editable.
Signatures disappeared after an edit.
By design. A signature belongs to the page version it was given against; publishing a new version resets the document to Draft and records that in the audit trail.
Where is the audit trail?
Per page: Document control → Show audit trail. Per space, as CSV: Space settings → Document control → Audit export.
