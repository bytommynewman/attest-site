Install Attest on your Confluence site.

It takes about two minutes. It's free during early access, with every feature, and there's nothing to pay and no card to enter.

Install AttestTalk to us first

You'll need to be an administrator of your Confluence Cloud site. The button opens Atlassian's own install screen.

How it works

  1. Install. Click Install Attest, choose your site, and review the permissions Atlassian shows you. Each one is explained on the Security page.
  2. Set up a space. Go to Space settings, Integrations, Document control. Add approvers with their roles, choose how many must sign and set a review period. Trying it alone? Also turn on "Let the person who submits or last edited a document also approve it".
  3. Place the record. On a page, insert the Approval signatures macro where the record belongs. Do this before you submit, because adding it later publishes a new version.
  4. Submit and sign. Open Document control under the page title and submit. Approvers get a page comment, tick the statement and approve.

What to know first

  • Attest is new, and it hasn't been used by a customer or been through a real audit yet.
  • It has been tested on a live test site with two user accounts. The Security page lists what has and hasn't been run, so try it in a test space first.
  • Approving a page restricts who can edit it. Everyone except the approvers, the owner and anyone already named loses edit access until the approval ends. Locking can be turned off per space.
  • It isn't on the Atlassian Marketplace yet. Billing can only start once it's listed, and you'd hear from us before that. Planned pricing is published so you can budget now.

If you stop using it

Uninstall it at any time. Export your audit trail first: Atlassian keeps an uninstalled app's data for 28 days, and it can only be recovered if you ask within 21. Any edit lock stays in place as an ordinary Confluence restriction until someone changes it, and the signature macro stops rendering.
